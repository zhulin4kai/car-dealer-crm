# 代码审查与交付清单

只检查与本次变更有关的项目；不适用项无需为了勾选而制造代码。

## 范围与行为

- [ ] 实际修改与用户要求、业务 Spec 和声明范围一致。
- [ ] 已明确必须保持不变的行为，没有顺手重构或退化兼容入口。
- [ ] 正常、边界、失败、重复请求和并发行为均有确定结果。
- [ ] 公共签名、配置、枚举和共享组件变化已检查全部调用方。
- [ ] 工作区中的他人修改未被覆盖、回退或混入本次交付。

## 后端

- [ ] Controller、Service、Manager、Mapper 和 Model 职责未越界。
- [ ] 当前用户、审计字段、权限和数据范围来自可信服务端上下文。
- [ ] 状态迁移校验旧状态，Mapper 写入检查影响行数。
- [ ] 多表写入、库存、支付、退款、审批和发票具有正确事务边界。
- [ ] 并发写入使用 CAS、锁或唯一约束，重复请求不会产生重复副作用。
- [ ] 缓存在事务提交后正确失效，缓存失败不会改变业务事实。
- [ ] 异常映射、日志和审计没有泄露敏感信息或重复记录堆栈。

## 数据库

- [ ] Schema、Mapper XML、Model、测试 Schema 和初始化数据保持同步。
- [ ] SQL 参数安全，无不受控 `${}`、空集合批量或无条件写入。
- [ ] 主外键类型、金额精度、状态 code、唯一约束和默认值一致。
- [ ] 新查询有稳定排序、分页上限和必要索引评估。
- [ ] 数据迁移包含兼容、回填、校验和回滚/继续策略。

## 前端

- [ ] 页面、模块 API、类型、Store 和共享层职责未越界。
- [ ] Props、Emits、表单 Schema、API 请求响应均有明确类型，无 `any` 掩盖问题。
- [ ] loading、空状态、失败、重复提交和高风险确认得到处理。
- [ ] 前端只依据 HTTP 状态和稳定 code 分支，不匹配中文 message。
- [ ] 路由和按钮权限只用于体验，未替代后端授权。
- [ ] 组件在目标桌面/移动视口无文字溢出、遮挡和不可操作控件。

## 契约与文档

- [ ] API、错误码或状态变化已同步后端测试、前端类型/映射和 `docs/api.md`。
- [ ] 架构、目录、环境或联调方式变化已更新对应技术文档。
- [ ] Rule、Spec 和 Todo 的状态有当前代码或测试证据，没有虚假完成标记。
- [ ] 文档中的路径、命令、类名和配置在当前仓库中真实存在。

## 测试与交付

- [ ] Bug 修复包含可复现原问题的回归测试。
- [ ] 已按影响面运行定向、模块或完整测试，未通过降低断言换取通过。
- [ ] 测试报告包含实际命令、结果数量、警告和未运行范围。
- [ ] `git diff --check`、完整 diff 和 `git status --short` 已检查。
- [ ] 没有调试代码、临时文件、后台进程、密钥和无关格式化。
- [ ] 仅在用户授权时执行 Git 操作，提交原子且提交信息准确。
