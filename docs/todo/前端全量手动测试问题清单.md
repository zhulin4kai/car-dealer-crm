## 问题列表

### Task_UI_FULL-001：工作台“录入线索”没有进入录入流程

- 页面：工作台
- 操作步骤：
  1. 登录后停留在 `/dashboard`。
  2. 点击“最新线索”区域右上角的“录入线索”按钮。
- 实际结果：页面跳转到 `/dashboard/clue`，只显示线索列表，没有打开新增线索表单。
- 预期结果：“录入线索”应直接进入新增线索流程，例如打开新增线索弹窗，或跳转到线索页后自动打开新增表单。
- 影响范围：工作台快捷入口语义不成立，用户点击后还需要再次点击线索页的“录入线索”，形成重复操作。
- 证据：浏览器手工测试，点击后 URL 为 `http://127.0.0.1:8081/dashboard/clue`，页面停留在线索列表。

### Task_UI_FULL-009：表格行操作按钮触发 Vue 运行时指令警告

- 页面：市场活动；后续其他列表页如复用同一行操作组件，也可能受影响。
- 操作步骤：
  1. 进入市场活动列表。
  2. 加载表格、点击编辑/删除等行操作按钮。

- 预期结果：权限指令和行操作按钮不应产生运行时警告；权限控制应绑定到真实 DOM 元素或由组件内部处理。
- 影响范围：如果 `v-has-permission` 未实际生效，可能导致无权限按钮仍可见或有权限按钮异常隐藏；同时大量警告会掩盖真正错误。
