## 覆盖要求

- 每个端到端场景至少覆盖一个业务闭环 Spec、一个模块 Spec、一个 Plan 和一个 Task。
- 每个场景必须包含通过标准和禁止行为。
- 代码实现完成后，应把这些场景转化为集成测试或人工验收脚本。
