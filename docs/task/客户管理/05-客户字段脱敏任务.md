# 客户字段脱敏任务

## 关联审计问题
- 无直接主关闭审计问题；本任务只作为业务域内独立执行任务。

## 当前错误行为
- 当前客户隐私字段可能由前端自行隐藏或未统一脱敏。

## 目标不变量
- 客户敏感字段必须由后端按权限脱敏。

## 前置依赖
- 无前置依赖。

## 允许修改范围
- `dealer-server` 中本任务直接涉及的 Controller、Service、Mapper、DTO、Model、枚举和测试。
- `dealer-web` 中本任务直接涉及的页面、API 模块、类型、枚举映射和测试。
- 本任务必须同步的数据库基线 SQL、OpenAPI、错误码和文档引用。

## 禁止修改范围
- 不得修改其他业务域负责关闭的主 Task。
- 不得通过删除历史事实、降低断言、放宽权限或吞掉异常让验证通过。
- 不得把多个业务动作重新压缩进一个通用 `stage`、中文字符串或布尔字段。
- 不得绕过后端规则只在前端隐藏入口。

## 契约变化
- API：按现有接口保持兼容；如新增或调整接口，必须同步 OpenAPI。
- DTO：按任务涉及的请求、响应对象补齐字段和校验。
- CodeEnum：涉及状态、类型、错误码时使用稳定英文 code。
- 数据库：涉及唯一性、外键、流水和历史事实时补齐迁移与兼容方案。
- 前端类型：涉及前端页面时同步 TypeScript 类型、枚举映射和错误码处理。

## 执行步骤
1. 盘点客户手机号、证件号、地址、微信、企业联系人等敏感字段。
2. 定义角色和场景对应的脱敏级别。
3. 后端列表、详情、选项接口统一返回脱敏结果。
4. 搜索和重复检查不得泄露越权客户完整信息。
5. 前端不保存或拼接未授权原文。
6. 补充不同角色可见性、搜索结果脱敏和导出前置测试。

## 测试
- 原问题回归：按关联审计问题或业务缺口构造失败前用例。
- 越权：涉及客户、交易、资金、票据、库存、导出时覆盖无权限路径。
- 重复请求：涉及创建、确认、退款、占用、导入、转化时覆盖幂等或冲突。
- 并发：涉及唯一业务键、库存、收款、退款、预算时覆盖并发竞争。
- 事务回滚：涉及多表写入时证明失败后无半成品。
- 契约：涉及接口或前端类型时同步 OpenAPI、DTO 和 TypeScript 类型。
