# 主动提醒摘要任务

## 任务目标

整理主动提醒、订阅规则、周期性摘要、主动事件和前端展示，保证提醒受权限、数据范围、频率和数量限制约束。

## 前置阅读

- docs/plan/AI业务助手/06-主动提醒与周期性摘要方案.md
- docs/rule/13-AI业务助手开发规范.md

## 允许修改范围

- dealer-server/src/main/java/com/autodealer/crm/ai/proactive/
- dealer-server/src/main/java/com/autodealer/crm/schedule/
- dealer-server/src/test/java/com/autodealer/crm/ai/proactive/
- dealer-web/src/modules/ai/components/AiProactivePanel.vue
- dealer-web/src/modules/ai/model/ai.types.ts
- dealer-web/src/modules/ai/api/ai-api.ts

## 禁止修改范围

- 不得直接访问 Mapper 重新拼业务统计口径。
- 不得修改普通业务状态。
- 不得向用户展示无权限数据或未脱敏敏感字段。
- 不得修改 `dealer-ai` 服务。

## 执行步骤

1. 审查主动订阅和主动事件模型。
2. 校验订阅暂停、恢复、取消。
3. 校验生成前重新加载用户和权限。
4. 校验频率、静默时间、数量上限和重复合并。
5. 周期性摘要复用已有业务只读口径。
6. 前端展示提醒列表、详情、订阅设置和摘要卡片。
7. 补齐无数据、失败、权限变化、用户停用和订阅取消测试。

## 完成条件

- 五类主动提醒可用。
- 主动提醒不修改业务状态。
- 用户停用或权限变化不泄露数据。
- 前端能展示和管理订阅。
