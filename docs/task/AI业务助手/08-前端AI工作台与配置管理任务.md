# 前端 AI 工作台与配置管理任务

## 任务目标

完成前端 AI 工作台和管理员 Provider 配置管理入口，让普通用户使用 AI 助手，管理员维护模型供应商配置。

- docs/plan/AI业务助手/07-前端AI工作台与管理入口方案.md
- docs/plan/AI业务助手/01-模型供应商配置与密钥治理方案.md
- docs/rule/13-AI业务助手开发规范.md

## 允许修改范围

- dealer-web/src/layouts/DashboardLayout.vue
- dealer-web/src/pages/dashboard/ai.vue
- dealer-web/src/modules/ai/
- dealer-web/src/router/routes.ts
- dealer-web/src/shared/constants/permissions.ts
- dealer-web/tests/
- docs/frontend.md

## 禁止修改范围

- 不得让前端直连 `dealer-ai`。
- 不得保存明文 API Key。
- 不得展示内部工具 JSON、模型 HTML、Provider 原始响应或 runtime config。
- 不得把普通业务页面改成 AI 链路。

## 执行步骤

1. 统一顶部 AI 入口、悬浮按钮、右侧栏和独立 AI 页面。
2. 对话面板复用同一套组件。
3. 展示消息、工具结果、Proposal、Workflow、主动提醒和上下文推荐。
4. 重构 AI 结果展示与执行细节降级。
   - `AiToolResultCard.vue` 必须去掉通用字段 key 直出，改为按业务对象类型渲染中文卡片。
   - 交易结果至少展示交易编号、客户、金额、状态、创建时间和建议动作。
   - `AiAssistantPanel.vue` 必须将业务结果放在主对话区，执行过程放入“查看处理过程”折叠区并默认关闭。
   - `AiAssistantPanel.vue` 必须移除固定工作流快捷按钮，动作入口只能来自当前问题和当前结果。
   - `AiWorkflowPanel.vue` 必须隐藏内部编号、内部步骤类型和工具 code，只展示中文业务步骤、状态和可执行控制。
   - 普通结果区不得展示 `id`、`tranNo`、`stageLabel`、`workflowNo`、`stepType`、内部事件名或内部 JSON。
5. 独立 AI 页面删除整条模型配置导航栏，改为右上角紧凑设置按钮。
6. 新增管理员 Provider 配置管理视图，使用 `crm-data-page`、`crm-panel`、表格列表和 Dialog 表单。
   - 页面顶部必须有“返回 AI 助手”按钮，点击回到 `/dashboard/ai`。
   - 配置列表的启用状态和测试状态必须使用 `StatusBadge` 或等价状态徽标展示，不得只显示普通文本。
   - 启用中的配置行必须有额外视觉提示，例如浅绿色行背景或左侧状态点。
   - 测试、启用、停用是表格行内主操作；编辑和轮换 API Key 是低频操作，必须放入更多菜单或独立低频操作区，禁止五个按钮无区分地挤在同一行。
7. 新增前端 Provider 预设常量，内置千问、DeepSeek、MiniMax、自定义 OpenAI-compatible 和自定义 Anthropic。
8. 已知 Provider 表单默认只显示厂商、区域或模型、配置名称和 API Key；Base URL、模型名和参数放入高级配置。
9. 自定义 Provider 表单必须显式填写协议格式、Base URL、模型名和模型展示名。
10. 所有输入项必须有字段 Label，不得只依赖 placeholder。
11. API Key 只允许新增和轮换时输入，轮换使用独立 Dialog，展示时只显示掩码。
12. 高级配置数值字段必须展示后端范围：timeout 1 到 60 秒、max output tokens 1 到 4096、temperature 0 到 2。
13. 高级配置数值字段必须前端提交前校验，失败时打开高级配置区域，字段下方显示错误，并通过 toast 提示。
14. Provider 配置新增、编辑、测试、启用、停用、轮换失败时必须展示后端错误摘要。
15. 增加测试连接、启用、停用和测试状态展示。
16. 补齐权限控制、类型检查、组件测试和浏览器验收。

## 完成条件

- 普通用户能使用 AI 工作台。
- 管理员能维护 Provider 配置。
- 独立 AI 页面不显示悬浮按钮。
- 独立 AI 页面模型配置入口不占用整条导航栏。
- Provider 配置页有返回 AI 工作台的明确按钮。
- Provider 配置列表能通过颜色和徽标区分启用状态、未启用状态、测试成功、测试失败和未测试。
- Provider 配置列表的编辑、轮换 API Key 不与测试、启停按钮混在同一个主操作区。
- 管理员新增千问、DeepSeek、MiniMax 配置时不需要手写 Base URL。
- Provider 配置表单字段都有可见 Label。
- 最大输出 Token 输入超过 4096 时，前端不发起请求并明确提示。
- 后端拒绝 Provider 配置提交时，页面显示错误提示，不要求用户查看后端日志。
- AI 默认展示业务结论和业务结果卡片，不默认展开执行过程。
- 待审批交易结果展示交易编号、客户、金额、状态、创建时间和建议动作。
- 普通结果区不展示 `id`、`tranNo`、`stageLabel`、`workflowNo`、`stepType`、工具 code 或内部 JSON。
- “查看处理过程”默认折叠，展开后仍使用中文业务步骤。
- `AiAssistantPanel.vue` 不固定展示“客户跟进”“交易缺口”“库存风险”等与当前问题无关的快捷工作流按钮。
- 右侧栏压缩主内容，不遮罩。
- 前端不出现 `dealer-ai` 直连。
