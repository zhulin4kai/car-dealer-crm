## 全局不变量

- LangGraph 是默认编排内核。
- Conversation 是多轮对话容器，Run 是 Conversation 中的一次执行；禁止把单次 Run 当作会话。
- 同一用户和同一业务对象上下文默认复用一个活跃 Conversation。
- Provider 配置由 Spring Boot 管理，`dealer-ai` 只接收本次运行所需的 `providerRuntimeConfig`。
- `providerRuntimeConfig` 不进入前端、SSE、trace、日志、Prompt 或模型上下文。
- OpenAI-compatible 和 Anthropic 都必须有 Adapter 边界和 mock 测试。
- 普通业务页面继续调用普通业务 API。
- 前端不直连 `dealer-ai`。
- `dealer-ai` 不访问数据库、Redis 会话、Mapper、文件写入、Shell 或通用 HTTP 工具。
- 高风险业务动作不得由 AI 直接执行。

## 全局禁止范围

- 禁止继续新增与旧分期路线绑定的任务。
- 禁止新增职责重复的 AI API 文件、AI 类型文件、AI 对话面板或 Provider 配置入口。
- 禁止在 `dealer-ai` 中保存管理员 API Key。
- 禁止把 API Key、Provider runtime config、服务间 token 写入日志或 trace。
- 禁止用编译通过代替功能验收。
