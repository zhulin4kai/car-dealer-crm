## 目标

- 固化后端模块化迁移的文件、Bean、Mapper、XML 和 API 基线。
- 建立能够随完整测试执行的模块依赖检查，不新增第三方依赖。
- 将经营分析作为首个业务模块迁入 `com.autodealer.crm.modules.analytics`。
- 保持统计数据范围、三个 HTTP 接口、AI 工具复用和 JSON 返回完全不变。

## 允许修改范围

- `docs/plan/后端架构/`、`docs/task/后端架构/`。
- `dealer-server` 中经营分析 Controller、Service、Manager、Result 及直接测试。
- 直接引用经营分析公开接口或返回类型的 AI 工具、Mapper、测试和 Mapper XML 类型声明。
- 本任务需要的架构测试和 `docs/backend.md` 经营分析路径。

## 禁止修改范围

- 不修改统计 SQL、指标口径、数据范围、权限码和接口路径。
- 不调整 `CurrentUserProvider`、业务 Mapper 和数据库 Schema。
- 不拆 `StatisticManager` 职责；专用 `AnalyticsMapper` 留到跨模块依赖收敛任务。
- 不顺带迁移其他业务类，不批量格式化无关文件。
