# 履约与 AI 域迁移任务

## 范围

- 履约域：`fulfillment.transaction`、`fulfillment.payment`、`fulfillment.invoice`、`fulfillment.delivery`。
- AI 域：`modules.ai` 的 Web、应用接口、内部实现、工具执行器、Mapper、Model 和 XML。
- 安全组合根迁入 `bootstrap.security`，AI 环境密钥策略归属 AI 模块。

## 落地约束

- 交易、支付、退款、发票、交付的锁、事务、状态机、幂等、审计和缓存语义不变。
- AI Conversation、Run、Proposal、Workflow、Tool 和 SSE 行为不变。
- XML 分别迁入 `resources/mapper/fulfillment/**` 与 `resources/mapper/ai/**`。
- 不保留旧 `ai`、`web`、`service`、`mapper`、`model` 包入口。

## 验证结果

- 履约与 AI 生产代码、测试和 XML 均已迁入目标模块。
- 干净构建能够加载全部 Mapper，AI Mapper 上下文契约读取新递归路径。
- 交易、支付、退款、发票、交付和 AI 用例已纳入 1039 项完整回归。
