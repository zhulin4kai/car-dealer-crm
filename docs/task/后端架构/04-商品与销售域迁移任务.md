# 商品与销售域迁移任务

## 范围

- 商品域：`commerce.catalog`、`commerce.inventory`、`commerce.promotion`、`commerce.quote`。
- 销售域：`sales.activity`、`sales.lead`、`sales.customer`、`sales.opportunity`、`sales.followup`、`sales.testdrive`。
- 同批迁移 Controller、应用接口与实现、公开模型、Mapper、XML 和单元测试。

## 落地约束

- HTTP 路径、JSON、权限码、SQL、事务和业务状态保持不变。
- 跨子域只依赖目标 `application.api`。
- 需要跨域传递的 `T*` 模型直接归属目标模块 `application.api.model`，不保留 persistence 副本。
- 跨域数据访问使用目标模块 `application.api.port`，调用方不注入其他模块 Mapper。

## 验证结果

- 商品与销售旧横向路径已清零。
- Mapper XML 已迁入 `resources/mapper/commerce/**` 与 `resources/mapper/sales/**`。
- 商品、库存、促销、报价、活动、线索、客户、商机、跟进和试驾测试已纳入完整回归。
