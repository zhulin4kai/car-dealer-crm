## 当前错误行为

- 展开侧栏只有退出图标，折叠状态点击头像直接退出。
- 通用用户更新接口允许登录账号和资料一起修改，没有本人资料字段白名单。

## 目标不变量

- 所有已登录普通人员和普通管理员都可以进入个人中心，修改自己的非授权资料并验证旧密码改密；固定恢复账号也保留本人非授权资料和独立专用联系方式入口，但密码恢复仍只能走 break-glass，本人会话管理由 Task 17 在此页面追加。
- 个人中心请求不能提交登录账号、员工编号、组织、岗位、管理者、角色、权限、数据范围和账号状态。
- 管理员可以修改自己的普通个人资料，但同样不能修改自己的授权信息。
- 固定恢复账号的个人中心不得开放组织任职、常规会话、用户治理或日常业务入口，其专用联系方式不计入普通管理员 `READY` 条件。

## 禁止修改范围

- 不复用管理员重置密码接口实现本人改密。
- 不让个人中心接收通用用户 Model 或万能更新 DTO。
- 不因前端隐藏字段而省略后端白名单和当前用户校验。

## API 契约

- 提供当前用户资料查询、白名单资料更新和本人改密接口。
- 个人资料响应可以只读展示员工编号、组织、岗位、管理者、角色和有效权限来源。
- 更新成功后返回最新个人资料；认证 Store 刷新左下角用户显示，不留下半更新状态。

## 执行步骤

1. 实现基于 `CurrentUserProvider` 的本人资料查询和白名单更新，不信任客户端用户 ID。
2. 实现姓名、电话、邮箱和头像地址校验、唯一性与版本冲突处理。
3. 接入 Task 15 的本人改密用例，成功后按安全规则撤销会话。
4. 新增个人中心页面，分为个人资料、修改密码和只读任职授权，并预留 Task 17 的本人会话分区。
5. 将左下角用户区域改为包含个人中心、修改密码和退出的菜单；折叠头像不直接退出。
6. 增加 `/dashboard/profile` 登录路由，不配置业务权限和动态菜单；普通账号均可从左下角进入，固定恢复账号只展示受限个人资料视图和当前状态允许的恢复入口。
7. 更新 Auth Store，资料更新成功后刷新当前用户，失败时不污染已有状态。
8. 同步路由测试、OpenAPI、前端类型、错误码和测试。

## 测试

- 本人可以修改白名单资料，不能提交或间接改变授权、任职和状态字段。
- 联系方式重复、格式错误和版本冲突返回稳定错误。
- 管理员修改自己普通资料成功，但修改自己角色或权限接口被拒绝。
- 本人改密要求旧密码，失败保留输入，成功后旧会话按规则失效。
- 左下角展开、折叠状态均可进入个人中心，只有明确点击退出才登出。
- Store 更新失败不改变当前用户，成功后页面与左下角显示一致。
