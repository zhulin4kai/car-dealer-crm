# 用户授权与变更历史基础任务

## 关联业务缺口

- UM-03：角色和权限关系只有当前态，无法解释授权来源和历史。
- UM-04：缺少个人增加、个人拒绝、有效期和数据范围事实。

## 当前错误行为

- `t_user_role` 和 `t_role_permission` 只保存当前关系，角色替换通过删除旧关系实现。
- 权限和密码变化复用账号状态审计，无法查询修改前后值、原因和有效期限。

## 目标不变量

- 角色、角色权限、用户角色、用户个人权限和组织任职变化均有不可变历史。
- 个人权限使用 `GRANT`、`DENY`，包含有效期、数据范围、原因和授权人。
- 业务事实与成功审计处于一致事务，审计失败时不得产生授权。

## 前置依赖

- 完成 `docs/task/用户权限/09-组织员工岗位基础模型任务.md`。

## 允许修改范围

- 用户、角色、权限关联及历史相关 Schema、Model、Mapper、XML、枚举和测试。
- `TRole`、`TPermission`、`t_user_role`、`t_role_permission` 的增量字段和映射。
- `AuditActionEnum`、`OperationAuditRecorder`、操作日志容量和直接测试。

## 禁止修改范围

- 不开放角色、权限或用户授权写接口。
- 不改变现有用户最终权限结果；本任务只建立可承载新规则的数据与审计基础。
- 不记录密码、密码哈希、Token、完整手机号或完整邮箱。

## 数据契约

- 角色增加说明、受保护标记、授权级别、默认数据范围、启停状态和版本。
- 权限增加模块、说明、敏感级别、可委派标记和启停状态。
- 角色权限关系增加是否可委派和对应数据范围。
- 用户角色增加授权人、原因、生效与失效时间。
- 用户个人权限同一用户、权限和当前版本保持唯一，历史通过不可变记录保存。
- 关系表新增字段先允许兼容默认值或可空；旧 Service 继续单写兼容字段，新授权 Service 切换和回填核验完成后才能收紧非空约束。
- `CUSTOM_ORGS` 在本任务只作为稳定数据范围 code 和约束值存在，具体组织关联表、可选组织集合和运行时范围计算由 Task 14 实现。
- Task 10 由统一 manifest 和迁移执行器调度；首次兼容回填、对象定义和后续步骤分别写入步骤账本，失败尝试只允许在相同 checksum 下 `resume`，已成功或 baseline 绑定后不得重放首跑回填。

## 执行步骤

1. 同步扩展生产 Schema、H2 Schema、初始化数据和迁移脚本。
2. 为现有内置角色和权限回填保护级别、授权级别、敏感级别和可委派默认值。
3. 新增用户个人权限和授权变更历史 Model、Mapper 及有效期查询。
4. 扩展审计动作，区分角色矩阵、用户角色、用户权限、组织、管理关系、密码和会话动作。
5. 扩大审计明细承载能力，并保持敏感字段清理和长度限制。
6. 建立授权事实和审计同事务写入的公共能力，不让 Mapper 决定业务审计。
7. 补充审计失败回滚、历史不可删除和到期过滤测试。
8. 接入 Task 21 的统一 manifest、命名锁、checksum、`RUNNING/SUCCEEDED/FAILED` 账本和步骤恢复；业务 DDL/回填过程内部二次校验执行上下文，全部步骤和对象探针成功后才能完成。

## 测试

- 多角色、用户角色和个人权限历史可解释且不物理删除。
- 有效期边界按统一时区判断，过期记录不进入当前态。
- 操作日志写入失败时授权写入整体回滚。
- 审计明细不包含密码、哈希、Token 和完整联系方式。
- 初始化数据的权限 code、敏感级别和可委派值与常量一致。
- H2 验证授权历史 Mapper 不提供更新、删除入口以及审计失败时事务回滚；H2 不替代生产触发器方言验证。
- Task 21 在真实 MySQL 和 MariaDB 旧库快照上验证首次执行、故障恢复、重复执行、baseline、`mysql --force` 防绕过和账本状态，并确认生产触发器拒绝授权历史 `UPDATE`、`DELETE`。

## 测试环境边界

- `schema-test.sql` 与 H2 测试用于验证字段、约束、Mapper 写入口和事务行为，不复制 MySQL/MariaDB 的 `SIGNAL` 触发器语法。
- “历史不可变”的 H2 证据仅表示应用 Mapper 没有更新或删除 statement；生产数据库的物理不可变性以 `CarDealerCRM.sql`、Task 10 迁移中的触发器及 Task 21 真实 MariaDB 验证结果为准。
- `CUSTOM_ORGS` 的具体组织关联和范围展开不在本任务测试中伪造，统一留给 Task 14。
