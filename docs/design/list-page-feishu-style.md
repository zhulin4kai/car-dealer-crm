# CRM 数据列表页飞书风格设计范式

## 文档定位

本文定义除 `/dashboard` 工作台首页之外，CRM 各类数据展示与管理页面的通用 UI 范式。产品列表视觉稿只作为普通列表页的参考样式，本文不记录外部设计稿路径，也不把参考稿中的静态数据视为本项目事实。

适用页面：

- 市场活动列表
- 线索列表
- 客户列表
- 交易列表
- 产品列表
- 产品分类、促销、库存预警
- 用户、字典等后台管理列表

不适用或需要单独设计的页面：

- `/dashboard` 工作台首页，继续遵守 `docs/design/dashboard-feishu-style.md`。
- 详情页、审批页、复杂表单页、客户 360 视图、交易结算页等流程型页面。
- 需要强业务引导的向导式页面。

## 设计判断

把“产品列表”作为普通数据页范式是合理的，因为 CRM 大多数管理页本质上都是查找、筛选、批量选择、执行动作和分页查看数据。但不建议所有页面完全复制产品页的字段和布局，应抽成三层范式：

1. 页面壳层统一：侧栏、顶栏、背景、间距、字体、颜色一致。
2. 数据页骨架统一：概要指标、工具栏、筛选区、表格、分页一致。
3. 业务字段差异化：每个领域保留自己的关键字段、状态、危险操作和权限按钮。

## 页面骨架

普通数据列表页使用单主栏结构，不使用 Dashboard 的右侧洞察栏。

```text
DashboardLayout.vue
  DashboardHeader
    页面标题 + 日期
    全局搜索入口
    AI 助手入口（可选）
    通知入口
    用户菜单

  ListPageContent
    SummaryCards
    ListPanel
      PanelHeader
      QueryToolbar
      DataTable
      PaginationBar
```

页面标题使用当前模块名称，例如“产品管理”“线索管理”“交易管理”。顶栏日期沿用全局格式，不在业务页内重复渲染。

## 规格参数

### 页面布局

| 项目 | 规格 |
| --- | --- |
| 页面背景 | `#F5F6F7` |
| 内容区 padding | 桌面端 `24px 32px`，窄屏 `16px` |
| 模块纵向间距 | `20px` |
| 左侧导航宽度 | 展开 `240px`，折叠 `64px` |
| 顶栏高度 | `56px` |
| 内容最大宽度 | 默认铺满剩余空间，不居中限制宽度 |
| 卡片圆角 | `8px` |
| 卡片边框 | `1px solid #EBEDF0` |
| 卡片阴影 | `0 1px 3px rgba(0, 0, 0, 0.04), 0 0 0 1px rgba(0, 0, 0, 0.02)` |

### 概要指标卡

列表页顶部可以放 2 到 4 张概要指标卡。没有可靠统计数据时不展示假数字。

| 项目 | 规格 |
| --- | --- |
| 栅格 | 桌面端 `repeat(4, minmax(0, 1fr))` |
| 卡片高度 | `108px` 到 `112px` |
| 卡片 padding | `24px` |
| 卡片间距 | `20px` |
| 图标块 | `52px * 52px`，圆角 `10px` |
| 图标或状态点 | 图标 `18px`，状态点 `10px` |
| 指标标题 | `13px`，`#8F959E` |
| 主数字 | `28px`，字重 `600`，`#1F2329` |
| 辅助口径 | `13px`，`#8F959E` |

产品列表示例指标：

- 产品总数：总产品数 + 分类数。
- 上架产品：上架数 + 总数。
- 库存预警：低于最低库存的产品数。
- 产品分类：启用分类数。

其他页面应换成对应领域指标。例如线索页可用“线索总数、待跟进、今日需联系、已转客户”，交易页可用“交易总数、待审批、已成交、异常退款”。

## 列表面板

列表主体使用一个白色面板承载工具栏、筛选区、表格和分页。

| 项目 | 规格 |
| --- | --- |
| 面板背景 | `#FFFFFF` |
| 面板圆角 | `8px` |
| 面板边框 | `1px solid #EBEDF0` |
| 面板溢出 | 横向滚动在表格区域内处理，不让页面整体横向滚动 |
| 面板头部高度 | `72px` |
| 面板头部 padding | `20px 24px` |
| 面板标题 | `18px`，字重 `600` |
| 数量 badge | 高 `24px`，padding `0 10px`，背景 `#F0F1F2`，文字 `#8F959E` |

面板头部左侧是标题和数量，例如“产品列表 12 条”；右侧是页面级主操作和次操作。

按钮规格：

| 类型 | 高度 | 用途 |
| --- | --- | --- |
| 主按钮 | `44px` | 新增、导入、创建 |
| 次按钮 | `44px` | 分类管理、促销设置、导出 |
| 危险按钮 | `44px` | 批量删除、下架、退款 |
| 图标按钮 | `40px * 40px` | 筛选、下载、刷新、列设置 |

按钮左侧优先使用 lucide 图标，例如 `Plus`、`Tag`、`Percent`、`TriangleAlert`、`Filter`、`Download`。仅图标按钮必须有 Tooltip 或 `aria-label`。

## 查询与筛选区

查询区位于面板头部下方，推荐高度 `64px`，padding `0 24px 20px`。

基础结构：

- 左侧搜索框。
- 中间快速分类或状态 tab。
- 右侧筛选、导出、列设置等图标按钮。

规格：

| 项目 | 规格 |
| --- | --- |
| 搜索框宽度 | `340px`，窄屏可变为 `100%` |
| 搜索框高度 | `44px` |
| 搜索框背景 | `#F5F6F7` |
| 搜索框圆角 | `8px` |
| 搜索图标 | `16px`，`#8F959E` |
| tab 高度 | `40px` |
| tab 水平 padding | `16px` |
| active tab | 背景 `#3370FF`，文字白色，圆角 `20px` |
| inactive tab | 背景透明，文字 `#646A73` |

产品列表示例 tab：

- 全部
- 整车
- 汽车配件
- 汽车用品
- 保养维修

其他页面应根据业务换成最常用筛选：

- 线索：全部、待跟进、有意向、已转客户、已流失。
- 交易：全部、待审批、跟进中、已成交、已失败。
- 活动：全部、进行中、未开始、已结束。
- 用户：全部、启用、禁用。

筛选层级建议：

1. 高频筛选放成 tab。
2. 中频筛选放到筛选弹层。
3. 低频字段不占据首屏工具栏，避免列表页变成表单页。

## 表格规范

表格是普通数据页的核心，应保持高密度但可读。

| 项目 | 规格 |
| --- | --- |
| 表头高度 | `52px` |
| 数据行高度 | `72px`，含图片或双行信息时可到 `84px` |
| 单元格横向 padding | `16px` |
| 表头背景 | `#F5F6F7` |
| 表头文字 | `13px`，字重 `500`，`#8F959E` |
| 正文文字 | `14px`，`#646A73` |
| 重点字段 | `14px`，字重 `500`，`#1F2329` |
| 行分隔线 | `1px solid #F0F1F2` |
| 行 hover | `#F5F6F7` |
| 勾选框列 | `56px` |
| 操作列 | `120px` 到 `160px`，右侧固定时可选 |

列宽建议：

| 列类型 | 宽度 |
| --- | --- |
| 选择列 | `56px` |
| 编号 / SKU / code | `140px` 到 `180px` |
| 主名称列 | `280px` 到 `360px` |
| 分类 / 负责人 / 来源 | `120px` 到 `160px` |
| 规格 / 描述摘要 | `160px` 到 `220px` |
| 金额 / 数量 | `100px` 到 `140px` |
| 时间 | `160px` 到 `180px` |
| 状态 | `110px` 到 `140px` |
| 操作 | `120px` 到 `160px` |

单元格表达：

- 编号、SKU、code 使用浅灰 pill，背景 `#F0F1F2`，高度 `24px`。
- 主名称列可以包含 `40px * 40px` 的业务图标块和名称。
- 金额显示保留业务单位，如 `¥16.58万`；普通金额使用千分位。
- 库存低于最低库存时用警告色，并保留文本或图标语义。
- 状态用 pill 或紧凑 badge，禁止只靠颜色区分。
- 操作按钮优先使用图标按钮：查看、编辑、删除。危险操作必须二次确认。

产品列表推荐列：

| 字段 | 表达 |
| --- | --- |
| SKU | 浅灰 pill |
| 产品名称 | 图标块 + 产品名 |
| 分类 | 文本 |
| 规格 | 文本 |
| 价格 | 金额文本 |
| 库存 | 数字，低库存用警告色 |
| 最低库存 | 数字 |
| 状态 | 上架 / 下架 badge |
| 操作 | 查看、编辑、删除 |

## 分页栏

分页栏固定在列表面板底部。

| 项目 | 规格 |
| --- | --- |
| 高度 | `68px` |
| padding | `0 24px` |
| 左侧 | 总数文案，例如“共 12 条记录” |
| 右侧 | 页码、上一页、下一页 |
| 当前页按钮 | `36px * 36px`，背景 `#3370FF`，文字白色 |
| 普通页码 | `36px * 36px`，文字 `#646A73` |
| 禁用翻页 | `#DEE0E3` |

分页必须来自真实 `PageResult.total`，不能依据当前页数组长度推断总数。

## 状态体系

普通列表页常用状态：

| 状态 | 文字色 | 背景色 | 适用 |
| --- | --- | --- | --- |
| 启用 / 上架 / 已成交 | `#34C759` | `#E8F8ED` | 正常可用、成功闭环 |
| 禁用 / 下架 | `#8F959E` | `#F0F1F2` | 不可用或历史状态 |
| 待处理 / 跟进中 | `#FF9500` | `#FFF4E5` | 需要后续动作 |
| 异常 / 低库存 / 已流失 | `#FF3B30` | `#FFEBE9` | 风险和异常 |
| 普通信息 | `#007AFF` | `#E5F1FF` | 信息提示 |
| 重点分类 | `#9B59B6` | `#F3E8FF` | 可选辅助类别 |

状态组件必须同时包含文本；圆点、颜色和图标只作为辅助。

## Vue 落地约束

实现普通列表页时必须遵守：

- 页面仍放在 `dealer-web/src/pages/dashboard/**`，只编排领域 API、composable 和业务组件。
- 领域组件放在 `dealer-web/src/modules/<domain>/components/`，不要写进 `components/ui/`。
- 基础控件继续使用 shadcn-vue：`Button`、`Card`、`Table`、`Input`、`Checkbox`、`Badge`、`Dialog`、`DropdownMenu`、`Tooltip`。
- 图标使用 `@lucide/vue`。
- 搜索、筛选、分页参数必须通过领域 API 的结构化 query 对象传递。
- 每个列表维护独立的 `query`、`currentPage`、`pageSize`、`total`、`loading`、`selectedIds`、`empty` 和 `error` 状态。
- 删除、下架、退款、审批拒绝等高风险操作必须二次确认。
- 库存、支付、审批等强一致业务禁止无回滚策略的乐观更新。
- 当前页加载失败时保留原查询条件，显示可重试入口。
- 表格空状态要给出下一步动作，例如“新增产品”或“调整筛选条件”。

## 设计建议

这个列表页范式适合统一 CRM 的展示型和管理型页面，但建议后续拆成可复用的“数据页壳层”能力，而不是每个页面复制一遍样式。

建议沉淀：

- `PageSummaryCards`：统一顶部指标卡。
- `DataPagePanel`：统一标题、数量、工具栏、表格、分页外壳。
- `DataPageToolbar`：统一搜索、tab、筛选和导出按钮。
- `StatusBadge`：统一状态颜色和文本映射。
- `RowActions`：统一查看、编辑、删除、更多操作。

但第一轮实现不必过度抽象。可以先挑产品列表和线索列表做样板，等两个领域都稳定后再抽共享组件，避免一开始就为了通用而牺牲业务字段表达。

## 验收标准

- 除 Dashboard 外的列表页首屏遵守“概要指标 + 列表面板 + 查询筛选 + 表格 + 分页”的结构。
- 不在代码或文档中引入 React、JSX、Recharts 等参考稿技术栈。
- 不展示静态假数据；接口未提供的统计项隐藏或显示明确空状态。
- 页面权限按钮继续遵守 `v-has-permission` 和后端授权。
- 表格在 `1440px`、`1920px`、`768px`、`375px` 视口下不发生文本重叠；窄屏允许表格横向滚动。
- 验证命令至少包括 `npm run typecheck`、`npm run lint`、`npm run build`。
