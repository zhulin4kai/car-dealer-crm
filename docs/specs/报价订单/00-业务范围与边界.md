# 报价订单业务范围与边界

## 业务目标

报价订单用于管理客户从价格方案确认到正式下单的过程，确保车型、配置、价格、优惠、订金、交付预期和客户承诺形成清晰业务事实。

报价是销售建议和谈判依据，订单是客户确认购买后的成交承诺。两者必须区分。

## 目标用户

- 销售人员：生成报价、提交价格协商和创建订单。
- 销售主管：审批超权限优惠、确认成交条件。
- 财务人员：依据订单确认收款责任。
- 库存人员：依据订单确认车辆占用和交付准备。
- 管理者：观察成交价格、折扣和订单质量。

## 功能范围

报价订单覆盖：

- 报价创建。
- 报价版本。
- 车型、配置和库存选择。
- 指导价、优惠、促销和附加费用摘要。
- 报价有效期。
- 报价审批。
- 客户接受报价。
- 订单创建。
- 合同或订单确认。
- 订金要求。
- 车辆占用。
- 订单变更。
- 订单取消。
- 赢单和输单联动。

## 报价信息

报价至少应表达：

- 客户。
- 商机。
- 车辆商品或库存车辆。
- 报价版本。
- 价格组成。
- 优惠来源。
- 有效期。
- 审批状态。
- 客户反馈。
- 是否被订单采用。

报价过期后不能直接作为新订单成交条件，必须重新确认或生成新版本。

## 订单信息

订单至少应表达：

- 客户。
- 关联商机。
- 成交车型或车辆。
- 成交价格。
- 优惠和权益。
- 订金或付款约定。
- 预计交付时间。
- 销售负责人。
- 订单状态。
- 取消或变更原因。

订单应成为收款、发票、库存占用和交付的共同业务基础。

## 非目标

报价订单不承担：

- 电子签章平台。
- 法律合同全文管理系统。
- 金融贷款审批。
- 保险承保。
- 支付清算。
- 税控开票系统。
- 车辆交付验收全流程。

## 成功标准

- 报价版本和订单成交事实清楚区分。
- 成交价格、优惠和促销来源可追溯。
- 超权限价格必须经过业务审批。
- 订单创建后能驱动收款、库存占用、发票和交付。
- 订单取消和变更保留原因，不破坏历史报价。
