# 库存管理流程规则与验收规格

## 主流程

### 入库

- 车辆到店或确认可销售后进入库存。
- 入库必须关联车辆商品，并记录车辆唯一识别信息、颜色、配置和所在位置。
- 未完成入库确认的车辆不能作为现车承诺给客户。

### 占用

- 试驾、销售锁定和订单占用应区分用途。
- 试驾占用只影响特定时间段车辆可用性。
- 销售锁定用于短时间保留意向车辆，应有有效期。
- 订单占用基于客户确认、订金或订单条件形成。
- 占用必须关联客户、商机、报价或订单之一。

### 释放

- 试驾结束、商机战败、订单取消、锁定过期等场景应释放库存。
- 释放应保留原因和触发业务对象。
- 库存释放不代表客户流失，客户和商机仍按各自规则处理。

### 出库与交付

- 车辆交付确认后进入出库或已交付状态。
- 出库必须与交付事实、订单和客户关联。
- 订单取消时不得保留已出库状态。

### 调整与盘点

- 库存调整必须有原因，区分盘点差异、状态修正、车辆损耗或管理决策。
- 盘点异常应进入待处理状态，不得直接覆盖为正常。

## 关键业务规则

- 商品库存数量不能替代具体库存车辆状态。
- 同一具体车辆同一时间只能有一个有效销售占用。
- 库存扣减不应在商机创建时发生。
- 库存锁定应有有效期和释放机制。
- 已交付车辆不得再次进入可售库存，除非经过明确退车或冲正流程。
- 库存变动必须可追溯，不能只保留最终数量。

## 指标要求

库存管理应支持观察：

- 可售库存数量。
- 已占用库存数量。
- 待交付车辆数量。
- 库存周转天数。
- 库存积压车辆。
- 热销车型库存不足。
- 盘点异常数量。
- 试驾车辆占用情况。

## 验收场景

- 新车入库后，销售能在可售库存中查询到对应车辆。
- 同一车辆被订单占用后，不能再被另一个订单占用。
- 销售锁定过期后，车辆恢复可售状态并保留释放原因。
- 订单取消后，已占用车辆释放回可售或指定状态。
- 交付完成后，车辆不再出现在可售库存中。
- 盘点异常车辆不能直接作为可售现车承诺。
- 管理者能查看库存周转和积压车辆清单。
