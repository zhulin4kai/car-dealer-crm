# 客户转换、查询与导出治理

## 目标

拆分客户查询和线索转客户命令，清除客户端可写审计字段，保护客户数据权限，并落实可控、安全的 Excel 导出。

## 当前问题

位置：

- `query/CustomerQuery.java`
- `web/CustomerController.java`
- `service/impl/CustomerServiceImpl.java`
- `manager/CustomerManager.java`
- `mapper/TCustomerMapper.xml`

`CustomerQuery` 同时包含列表筛选、clueId、product、description、quantity 和 createBy，仍被列表与转换命令共用。客户转换的操作者已经改为当前登录用户，但 DTO 仍暴露 createBy，契约没有闭环。导出未传 IDs 时把 idList 设为 null，实际仍可能查询全部客户，注释中的 10000 条限制没有生效。

## 文件所有权

允许修改：

- Customer、CustomerRemark 相关 Controller、Service、Manager、Model、DTO、Query、Mapper 和 XML
- `result/CustomerExcel.java`、`dto/CustomerOption.java`
- 客户转换、列表、详情、导出和备注测试
- `dealer-web/src/modules/customer/`、客户页面和对应测试

禁止修改线索模块、商品模块、Schema、公共错误码、Redis 基础类和审计基础文件。

## 修改方案

### 请求与响应契约

1. 拆分 `CustomerListQuery`、`ConvertCustomerRequest`、客户更新/备注 Request；删除 CustomerQuery 中混合字段。
2. 查询对象只包含筛选和分页；转换请求只包含 clueId、选购商品、数量、描述和下次联系时间。
3. 删除 createBy 等客户端审计字段，操作者只来自 `CurrentUserProvider`。
4. 列表和详情返回明确 Response DTO，禁止直接暴露包含内部关联和审计字段的 TCustomer。
5. 显式声明 Query 的 equals/hashCode 父类策略。

### 转换一致性

1. 线索转客户前锁定或使用唯一约束确认未转换，防止并发重复转换。
2. 验证线索存在、当前用户有权限、商品存在且允许选择、quantity 大于零。
3. 客户、线索状态和转换关联在同一事务中完成，任一步失败全部回滚。
4. 保留已完成的可信当前用户来源，不重新接收客户端 createBy。

### 查询与数据权限

1. 客户列表、详情、选项、备注和导出使用同一数据权限条件。
2. Mapper 禁止依赖客户端 createBy 过滤数据，数据范围由 Service/Aspect 注入的结构化字段决定。
3. 列表分页和排序稳定，避免重复接口 `/api/customer/list` 与 `/api/customers` 长期表达同一能力；保留一个正式契约并处理兼容。

### Excel 导出

1. 明确同步导出上限为 10000 条；未传 IDs 时也必须在 SQL/Service 强制上限，禁止 null 表示无限制。
2. 传 IDs 时去重、校验数量、逐项应用数据权限，禁止导出无权客户。
3. 导出前可执行 count；超限返回稳定业务错误，不开始写响应体。
4. 设置正确 Excel Content-Type、RFC 兼容文件名和安全响应头。
5. 防止公式注入：文本以 `= + - @` 开头时转义。
6. 导出字段使用白名单和脱敏策略，不包含内部权限、Token、完整敏感备注。
7. 数据量未来超过同步能力时另立异步导出任务，本次不伪装成已支持。

### SQL、权限与审计

- 审查 Customer Mapper XML 的数据权限、join、分页、导出上限和删除策略。
- 客户敏感读、转换、备注和导出均检查后端权限。
- 审计转换、归属变化、资料修改和导出；导出审计记录条件摘要和数量，不记录完整数据。

## 测试

- CustomerListQuery 不包含命令字段，ConvertCustomerRequest 不包含 createBy。
- 客户端伪造操作人无法改变审计身份。
- 并发重复转换只有一次成功，失败路径不产生半条客户记录。
- 无数据权限的列表、详情、备注和导出均不可访问。
- 未传 IDs 导出最多 10000 条，传入超过上限或无权限 ID 时在写响应前失败。
- Excel 文件名、Content-Type、公式转义和字段白名单测试。
- 前端客户列表、转换表单、导出错误码和 loading 测试。

## 验收

- 查询与转换不再共用 CustomerQuery。
- 转换操作者和数据权限完全来自服务端上下文。
- 导出限制在所有入口真实生效，不存在全量无界查询。
- 客户 Mapper、权限、事务和导出安全有自动化测试保护。
