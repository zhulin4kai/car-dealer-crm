# 系统配置与监控契约治理

## 状态

已废止。

## 废止原因

2026-06-22 的产品决策确认：原“系统管理”模块是为功能展示临时加入，不符合当前汽车经销商 CRM 的业务目标。管理员需要的是登录记录和关键操作追溯，而不是系统配置 CRUD、服务器硬件监控或 JVM/CPU/内存/磁盘/网络监控。

因此本 Plan 不再执行，也不得继续作为后续 Agent 的任务来源。

## 替代方向

- 新业务方向：审计日志。
- 规格目录：`docs/specs/审计日志/`。
- 当前执行计划：`docs/todo/2026-06-22-审计日志模块落地计划.md`。

## 已下线范围

- 系统配置页面和前端 system 模块。
- 系统配置后端 Controller、Service、DTO、Model、Mapper 和 XML。
- 系统监控后端 Controller、Service 和 DTO。
- `t_system_info` 表和初始化数据。
- `system:*` 与 `monitor:view` 权限。

## 保留边界

操作审计基础链路继续保留，但不再包含“系统配置更新”这一业务动作。后续审计日志模块应围绕登录记录和关键业务操作记录建设。
