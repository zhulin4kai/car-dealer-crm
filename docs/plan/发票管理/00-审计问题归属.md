## 归属原则
- 本文件只记录 `发票管理` 业务域内负责主关闭的审计问题。
- 一个审计问题只能有一个主关闭 Task；其他业务域只在前置依赖中引用。
- 跨模块依赖引用对应业务目录下的 Task，不建立中心化任务目录。

## 验收要求
- 主关闭 Task 完成后，交付说明必须写明审计问题 ID、验证命令和完成证据。
- 依赖 Task 未完成时，不得宣称主审计问题已经关闭。
- 不引用已废弃的中心化目录。
