# 现有 AI 实现审查与收敛方案

## 关联 Spec

- docs/spec/AI业务助手/00-业务范围与边界.md

## 审查结论

现有 AI 实现已经具备部分基础能力，但实现形态仍保留旧分期路线。主要问题是编排路线分裂、Provider 配置没有进入系统管理、Spring Boot 与 `dealer-ai` 的运行契约缺少 Provider runtime config。

## 必须删除

- 目标架构中的 `simple/langgraph` 路线选择。
- 以 `dealer-ai` 本地 env 作为正式模型配置来源的设计。
- 前端、计划或任务中“先不接入 LangGraph”“后置 LangGraph”的表达。
- 只为旧分期服务的 Proposal 空数组边界和 UI 收回任务描述。

## 必须保留

- `dealer-ai` 独立服务边界。
- Spring Boot 内部 Tool API 和 ToolRegistry 安全边界。
- AI Run、Message、ToolCall、Proposal、Approval、Workflow、主动事件追踪表。
- 前端 AI 面板、工具结果、Proposal、Workflow、主动提醒等已有组件的可复用部分。
- 禁止危险工具、禁止直连数据库、禁止前端直连 `dealer-ai` 的安全红线。

## 必须迁移

- `dealer-ai/app/orchestrator/langgraph_adapter.py` 迁移为默认编排入口。
- `dealer-ai/app/providers/openai_compatible.py` 中的 `OpenAICompatibleProvider` 改为接收 `providerRuntimeConfig`。
- Spring Boot `DealerAiRunRequest` 和 Python `ChatRunRequest` 增加 Provider runtime config。
- `dealer-server/src/main/java/com/autodealer/crm/ai/service/DealerAiClient.java` 增加 Provider runtime config 服务间传递能力。
- Provider Base URL、模型名、API Key 从 `dealer-ai` env 迁移到 Spring Boot Provider 配置。
- 前端 AI 工作台增加 Provider 配置管理入口。

## 必须重写

- `dealer-ai/app/api/routes/runs.py`：运行入口固定创建 LangGraph 编排器。
- `dealer-ai/app/core/config.py`：保留服务配置和 Tool API 配置，移除正式模型配置来源职责。
- `dealer-ai/app/orchestrator/simple.py`：目标架构不再作为主编排器使用。
- `dealer-server/src/main/java/com/autodealer/crm/ai/dto/DealerAiRunRequest.java`：补齐 Provider runtime config。
- `dealer-server/src/main/java/com/autodealer/crm/ai/service/DealerAiClient.java`：调用 `dealer-ai` 时必须携带 Provider runtime config。
- `dealer-server/src/main/java/com/autodealer/crm/ai/service/impl/AiConversationServiceImpl.java`：Run 启动前必须读取启用 Provider 配置。
- OpenAPI 和前端 API 类型：补齐 Provider 配置管理接口。

## 代码证据

- `dealer-ai/app/api/routes/runs.py` 必须固定创建 LangGraph 编排器。
- `dealer-ai/app/core/config.py` 只能保留服务运行参数和 Tool API 配置，不能承载正式模型配置来源。
- `dealer-ai/app/providers/openai_compatible.py` 中的 `OpenAICompatibleProvider` 必须从请求级 Provider runtime config 读取 Provider 信息。
- `dealer-server/src/main/java/com/autodealer/crm/ai/dto/DealerAiRunRequest.java` 必须携带 Provider runtime config。
- `dealer-server/src/main/java/com/autodealer/crm/ai/service/DealerAiClient.java` 必须在服务间请求中传递 Provider runtime config。
- `dealer-server/src/main/java/com/autodealer/crm/ai/service/impl/AiConversationServiceImpl.java` 必须在启动 Run 前读取启用 Provider 配置。
- 前端 AI 模块必须提供受权限控制的 Provider 配置管理页面。

## 收敛验收

- 代码实现任务开始前必须先完成本方案对应审查任务。
- 审查任务必须输出文件级处理清单：删除、保留、迁移、重写。
- 后续代码实现不得继续引入目标架构外的旧路线。
