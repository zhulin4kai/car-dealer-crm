# 前端 AI 工作台与管理入口方案

## 关联 Spec

- docs/spec/AI业务助手/00-业务范围与边界.md

## 背景

AI 前端需要同时承载普通用户的工作台体验和管理员的模型配置管理。它不能只是一个聊天窗口，也不能通过隐藏按钮绕过后端安全规则。

## 目标

- 顶部 AI 入口和右下角悬浮入口打开同一个右侧栏。
- 独立 AI 页面复用同一套对话面板。
- 独立 AI 页面只在右上角提供紧凑模型配置入口，不占用整条导航栏。
- 右侧栏压缩主内容，不做遮罩或 Dialog。
- 工作台展示消息、工具结果、Proposal、Workflow、主动提醒和上下文推荐。
- 管理员可维护 Provider 配置并测试连接。

## 工作台结构

- 消息区。
- 业务结果卡片区。
- Proposal 确认区。
- 当前动作区。
- 查看处理过程折叠区。
- 主动提醒区。
- 上下文推荐问题区。
- 错误和空状态区。

## 对话结果展示方案

- AI 回答按“回答摘要、业务结果卡片、当前动作、可选过程”组织。
- 回答摘要说明业务结论，例如“当前有 1 笔待审批交易，需要及时处理”。
- 业务结果卡片按 CRM 对象类型渲染，不直接展示接口字段名、内部工具名或原始 JSON。
- 交易卡片必须展示交易编号、客户、金额、状态、创建时间和建议动作。
- 金额、时间、状态必须格式化为销售、财务和主管能直接理解的业务文案。
- Workflow、工具调用和运行追踪进入“查看处理过程”折叠区，默认关闭，展开后仍只展示中文业务步骤。
- 普通问答结果默认不得展示 `workflowNo`、`stepType`、`stageLabel`、`tranNo`、工具 code 或内部事件名。
- “客户跟进”“交易缺口”“库存风险”等工作流入口只能在当前问题和当前结果需要时展示，不能作为每次回答固定按钮。

## Provider 配置管理 UI

- 配置页使用项目通用数据页风格：`crm-data-page`、`crm-panel`、表格列表和 Dialog 表单。
- 模型配置入口是 AI 工作台右上角紧凑设置按钮，不能使用整条顶部导航栏。
- 模型配置页必须提供返回 AI 工作台的明确按钮，不能要求用户依赖浏览器返回。
- 创建和编辑表单必须使用明确字段 Label，不能只依赖 placeholder。
- API Key 写入和轮换必须使用独立输入流程。
- 掩码展示。
- 测试连接。
- 启用和停用。
- 测试状态和错误摘要。
- 列表中的启用状态、测试状态必须使用状态徽标和颜色区分，不能只靠文字。
- 常用操作和低频操作必须分层：测试、启用、停用作为行内主操作；编辑、轮换 API Key 放入更多菜单或同等低频操作区，避免所有按钮挤在一行。

## Provider 预设

- 前端内置常用 Provider 预设，默认降低管理员配置成本。
- 千问（阿里云百炼）使用 OpenAI-compatible，提供中国北京、新加坡、美国弗吉尼亚、香港区域选项，默认模型为 `qwen-plus`。
- 深度求索（DeepSeek）使用 OpenAI-compatible，默认 Base URL 为 `https://api.deepseek.com`，默认模型为 `deepseek-v4-pro`，兼容旧模型放在下拉末尾。
- MiniMax 使用 OpenAI-compatible，默认 Base URL 为 `https://api.minimax.io/v1`，默认模型为 `MiniMax-M3`。
- 已知 Provider 默认只需要选择厂商、区域或模型并填写 API Key；Base URL、模型名、timeout、max output tokens 和 temperature 放入高级配置。
- 高级配置中的 timeout、max output tokens 和 temperature 必须展示后端一致的取值范围，并在前端提交前校验；校验失败时必须在字段下方和 toast 中明确提示。
- Provider 配置接口返回业务错误时，前端必须展示后端错误摘要，不能只在控制台或后端日志中暴露失败原因。
- 自定义 OpenAI-compatible 和自定义 Anthropic 保留完整高级配置能力。

## 安全边界

- 前端不保存明文 API Key。
- 前端不保存服务间 token。
- 前端不直连 `dealer-ai`。
- 前端不展示内部工具 JSON、模型 HTML、Provider 原始响应或 `providerRuntimeConfig`。
- Provider 配置页面必须受 `ai:provider-config:*` 权限控制。

## 验收标准

- 普通用户能使用 AI 工作台但不能进入 Provider 配置管理。
- 管理员能管理模型配置。
- 管理员新增千问、DeepSeek、MiniMax 配置时不需要手写 Base URL。
- 悬浮按钮、顶部按钮、右侧栏和独立页面行为一致。
- 刷新后能恢复 Run trace。
- 前端扫描无 `dealer-ai` 直连地址。
