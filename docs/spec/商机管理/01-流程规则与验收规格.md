# 商机管理流程规则与验收规格

## 主流程

### 创建商机

- 商机应基于已识别客户创建，也可以由高质量线索转化时同步创建。
- 创建商机必须有客户、意向车型或需求、负责人和初始阶段。
- 同一客户可以有多个商机，但同一购车需求不应被重复创建。
- 商机来源应继承客户或线索来源，并允许记录二次影响来源。

### 阶段推进

- 阶段推进必须基于真实业务动作。
- 从需求确认进入报价中，应已有明确车型、配置、预算或关键购买条件。
- 进入待签约前，应已有客户接受的报价或主管确认的成交条件。
- 赢单应形成订单或合同关系。
- 输单、搁置和关闭必须填写原因。

### 停滞处理

- 商机长期无跟进、无下一步动作或阶段停留过久时，应被识别为停滞。
- 主管可以督促、转派、搁置或关闭停滞商机。
- 停滞不等于输单，必须经过销售判断或客户明确反馈。

### 赢单与输单

- 赢单表示客户确认购买并进入订单流程。
- 输单表示该购车需求已失去推进价值。
- 输单原因应区分价格、竞品、预算不足、需求变化、库存不足、联系不上、服务半径等类别。
- 输单商机可以重启，但必须保留原关闭事实。

## 关键业务规则

- 商机阶段不应由订单、付款、发票单向覆盖。
- 商机金额是销售预测金额，订单金额是成交事实，两者必须区分。
- 商机预计成交时间用于预测，不代表交付日期。
- 商机负责人应明确，协作人员不能替代主负责人。
- 商机删除应受严格限制，已有报价、试驾或订单关系时不得普通删除。
- 价格审批属于报价或订单规则，商机只引用审批结果。

## 漏斗指标

商机应支持统计：

- 各阶段商机数量。
- 各阶段预计金额。
- 阶段转化率。
- 阶段停留时间。
- 赢单率。
- 输单原因分布。
- 销售人员商机推进质量。
- 来源到商机、商机到成交的转化效率。

## 验收场景

- 客户产生明确购车需求后，可以创建商机且不强制创建订单。
- 商机从需求确认推进到报价中时，必须具备明确车型或购买条件。
- 商机输单时必须选择原因，并保留竞品或客户反馈摘要。
- 赢单商机进入订单流程后，商机阶段显示已赢单，但收款和交付状态仍在对应业务中管理。
- 长期未跟进商机出现在主管关注范围内。
- 管理者能查看按阶段分布的销售漏斗。
- 普通销售不能查看超出数据范围的商机。

## 状态与事件边界

- 拥有状态：初步意向、需求确认、车型匹配、试驾邀约、报价中、协商中、待审批、赢单、输单、搁置和关闭。
- 消费事件：客户创建、跟进完成、试驾完成、报价提交、报价审批、客户确认订单和订单取消。
- 发出事件：商机创建、阶段推进、停滞提醒、赢单、输单、搁置和关闭。
- 终态包括赢单、输单和关闭；搁置为可恢复态。
- 不允许商机阶段承载订单、收款、发票、库存或交付状态。
