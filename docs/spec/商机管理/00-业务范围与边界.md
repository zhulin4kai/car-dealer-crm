# 商机管理业务范围与边界

## 业务目标

商机管理用于管理客户明确购车需求后的销售机会，跟踪从需求确认、车型匹配、试驾、报价、协商、审批到赢单或输单的完整过程。

商机是销售漏斗的核心对象。客户可以长期存在，但商机必须有明确购车需求、阶段、预计金额、负责人和关闭结果。

## 目标用户

- 销售人员：推进商机阶段、记录需求和执行下一步动作。
- 销售主管：查看漏斗、督促停滞商机、审批关键价格或资源。
- 市场人员：观察来源质量和活动带来的商机价值。
- 管理者：评估销售预测、成交概率和阶段转化。

## 功能范围

商机管理覆盖：

- 商机创建。
- 客户关联。
- 需求确认。
- 意向车型和配置。
- 预算、购车时间和竞品情况。
- 阶段推进。
- 成交概率。
- 预计成交金额。
- 下一步动作。
- 跟进历史。
- 关联试驾。
- 关联报价。
- 赢单、输单、搁置和关闭。
- 输单原因和竞品归因。

## 商机阶段

商机阶段应至少包含：

- 初步接触。
- 需求确认。
- 车型匹配。
- 已预约到店或试驾。
- 报价中。
- 价格协商。
- 待审批。
- 待签约。
- 已赢单。
- 已输单。
- 已搁置。

阶段应表达销售推进进度，不应混入收款、开票或交付状态。

## 非目标

商机管理不承担：

- 订单履约。
- 收款确认。
- 发票开具。
- 车辆交付。
- 金融贷款审批。
- 保险销售全流程。
- 售后维修机会管理。

商机赢单后进入订单和履约管理；商机本身不继续承担财务和交付状态。

## 成功标准

- 每个明确购车需求都有独立商机承载。
- 管理者能按阶段看到销售漏斗和停滞风险。
- 销售能够看到每个商机的下一步动作和预计成交时间。
- 输单原因能够沉淀为业务分析数据。
- 赢单商机能形成报价或订单关系，但不会直接跳过必要确认。

## 业务对象关系

- 上游对象：客户、高质量线索、跟进结果和试驾结果。
- 下游对象：跟进任务、试驾、报价、订单、经营分析和销售漏斗。
- 本模块负责购车需求、意向车型、阶段推进、预计金额、赢单、输单、搁置和停滞识别。
- 本模块不负责报价版本、客户确认订单、收款、发票、库存出库和交付完成状态。
- 商机赢单应以订单成立为依据，赢单后商机保留结果事实，后续履约由订单和交易履约管理。
