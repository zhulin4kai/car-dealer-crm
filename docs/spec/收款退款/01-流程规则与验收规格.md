# 收款退款流程规则与验收规格

## 主流程

### 收款计划

- 订单成立时应形成订金、尾款或全款等收款要求。
- 收款计划应明确金额、预计时间和责任人。
- 收款计划可以调整，但必须保留原因。

### 收款登记

- 销售或财务可以登记客户付款事实。
- 收款登记应包含订单、金额、类型、方式、付款时间和凭证摘要。
- 登记不等于财务确认。
- 收款凭证应受权限控制，不得随意公开。

### 收款确认

- 财务确认后，收款才计入实收。
- 确认失败或退回时，应说明原因。
- 多笔收款可以共同满足订单应收。
- 实收达到要求后，可以推动履约进入下一步。

### 退款

- 退款应基于订单取消、多收、价格调整或业务纠错产生。
- 退款申请必须说明原因、金额和关联原收款。
- 退款审批通过后进入退款执行或结果确认。
- 退款完成后应更新订单资金状态，但保留原收款和退款两条事实。

### 可退金额

- 可退金额 = 已确认有效收款 - 已完成退款 - 已批准或执行中的冻结退款金额 - 已完成冲正金额。
- 已确认有效收款只包括财务确认成功且未作废、未退回的收款原始金额。
- 已批准或执行中的冻结退款金额包括待执行退款和执行中退款。
- 待审批退款不减少业务可退金额，但占用可申请退款额度；待审批金额未释放前，不得再次申请导致申请总额超过可退金额。
- 退款审批通过后，退款金额应冻结；退款完成后转为已完成退款。
- 退款执行失败后，如果确认不再重试，应释放冻结金额；如果保留为待执行重试，冻结金额不得释放。
- 同一订单允许多次部分退款，但累计退款、冻结退款和已完成冲正不得超过已确认有效收款。
- 同一笔收款允许多次部分退款，但必须记录每次退款金额，累计不得超过该笔收款剩余可退金额。
- 退款应优先关联原收款；跨多笔收款分摊退款时，每一笔分摊都必须明确原收款和金额。
- 收款冲正用于纠正重复入账、错误入账或渠道回滚，不等同于业务退款；业务退款表示因订单取消、多收、价格调整或客户权益返还而向客户退还资金。

### 退款状态与职责

- 退款申请由销售、财务或具备授权的业务人员发起。
- 待审批退款应由主管、财务或授权角色审批，申请人不得审批自己的退款申请。
- 审批通过后进入待执行，由财务执行或确认外部退款结果。
- 已完成退款应保留执行时间、执行人、退款方式、外部参考号和关联原收款。
- 已驳回退款应保留驳回原因，不占用可退额度。
- 执行失败退款应保留失败原因，并明确是重新执行、重新申请还是释放额度。
- 已撤销退款只能发生在退款完成前；退款完成后不得撤销，只能进入新的纠错或补充退款流程。

## 关键业务规则

- 收款登记和财务确认必须区分。
- 每笔外部收款或退款参考号应具备幂等识别能力，重复提交不能重复入账。
- 每一笔成功收款、退款、退回和冲正都必须可审计，而不是只审计最终完成动作。
- 退款不能直接删除原收款。
- 订单取消不代表自动退款完成。
- 未确认收款不得作为交易完成依据。
- 退款金额不得超过可退金额，除非有明确纠错流程。
- 待审批、待执行和执行中的退款不得绕过额度校验。
- 收款冲正必须关联原收款和冲正原因，不得作为普通退款替代流程。
- 业务退款必须经过申请、审批、执行和结果确认，不得由单一操作直接完成。
- 收款和退款导出应受独立权限控制。
- 金额展示应保持统一币种和精度口径。

## 指标要求

收款退款应支持观察：

- 订单应收金额。
- 已确认收款金额。
- 未确认收款金额。
- 欠款金额。
- 逾期应收数量。
- 退款申请数量。
- 已完成退款金额。
- 异常资金记录。

## 验收场景

- 订单创建后，可看到订金或尾款应收要求。
- 销售登记收款后，资金状态为待确认而不是已收。
- 财务确认收款后，订单实收金额增加。
- 收款被退回时，销售能看到退回原因。
- 订单取消后，可以发起退款申请，但原收款记录仍保留。
- 退款完成后，订单资金视图同时展示原收款和退款事实。
- 未确认收款不能使交易进入已完成。
- 同一订单多次部分退款时，累计金额不能超过可退金额。
- 同一笔收款多次部分退款时，累计退款不能超过该笔收款剩余可退金额。
- 待审批退款占用可申请退款额度，审批驳回或撤销后额度恢复。
- 退款执行失败且不再重试时，冻结额度恢复；继续执行时额度仍冻结。
- 冲正完成后，该部分金额不能再作为可退金额发起业务退款。

## 状态与事件边界

- 拥有收款状态：待确认、已确认、已退回、已冲正和已作废。
- 拥有退款状态：退款申请、待审批、待执行、已完成、已驳回、执行失败和已撤销。
- 消费事件：订单成立、财务到账、订单取消、退款申请、退款审批、退款执行、退款失败和冲正申请。
- 发出事件：收款确认、收款退回、退款审批通过、退款驳回、退款执行、退款完成、退款失败、冲正完成和资金异常提醒。
- 收款终态包括已确认、已退回、已冲正和已作废；待确认为可处理态。
- 退款终态包括已完成、已驳回、执行失败和已撤销；退款申请、待审批和待执行为可处理态。
- 不允许资金状态覆盖发票状态、交付状态和交易最终状态。
