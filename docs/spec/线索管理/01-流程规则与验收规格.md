# 线索管理流程规则与验收规格

## 主流程

### 线索进入

- 线索可以由人工登记、批量导入、市场活动沉淀或外部渠道接入形成。
- 新线索进入后必须保留来源、进入时间和初始责任归属。
- 来源不明确时可以标记为未知来源，但不得伪造来源。
- 批量导入必须给出成功、失败和重复数量摘要。

### 线索查重

查重至少应考虑：

- 手机号。
- 备用联系方式。
- 客户姓名与联系方式组合。
- 已有客户。
- 已有进行中线索。

疑似重复不应自动覆盖已有资料，应由具备权限的人员确认合并、忽略或保留。

### 分配与认领

- 线索可以由主管分配给销售，也可以在规则允许时由销售认领。
- 分配必须明确负责人和分配时间。
- 负责人变更必须保留变更前后责任人和原因。
- 长期未跟进线索可以被主管回收或重新分配。

### 跟进与培育

- 销售每次有效沟通应记录跟进方式、沟通结论和下一步计划。
- 约到店、约试驾、补资料、再报价等动作应体现为下一步任务。
- 未联系上客户不能直接标记为无效，必须达到约定次数或时间条件。
- 客户明确拒绝、失联、竞品成交等情况应记录战败或无效原因。

### 转化

- 线索具备明确真实客户身份后，可以转为客户。
- 线索具备明确购车需求和推进价值后，可以关联或创建商机。
- 已转化线索不应继续作为新线索重复分配。
- 转化后线索来源、跟进历史和责任链条必须可追溯。

## 关键业务规则

- 同一手机号在同一门店或同一组织范围内不得产生多个互相独立的活跃线索。
- 线索负责人只能处理自己有权访问的线索。
- 线索导出必须受独立权限控制。
- 无效、重复、战败等关闭状态必须有原因。
- 关闭后的线索原则上不可继续编辑核心信息；如需恢复，必须产生恢复原因。
- 来源、状态、意向等级、战败原因必须使用统一业务口径。

## 质量指标

线索管理应支持观察：

- 新线索数量。
- 线索响应时长。
- 分配完成率。
- 跟进及时率。
- 转客户率。
- 转商机率。
- 战败原因分布。
- 来源转化质量。

## 验收场景

- 人工新增线索后，线索处于新线索或待跟进状态，并有来源和负责人。
- 导入包含重复联系方式的线索时，系统能够识别重复并给出处理结果。
- 销售记录跟进后，线索最近跟进时间和下一步计划发生变化。
- 主管将线索转派给另一名销售后，责任归属变化可追溯。
- 线索转客户后，客户能看到线索来源和历史沟通。
- 线索转商机后，不会直接产生订单、收款或发票。
- 无权限用户不能查看、导出或转派不属于自己范围的线索。
