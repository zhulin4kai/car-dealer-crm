# 促销政策流程规则与验收规格

## 主流程

### 促销创建

- 促销创建时应明确主题、类型、适用范围、优惠内容、有效期和负责人。
- 草稿促销不能被销售用于报价。
- 促销内容涉及赠品或服务权益时，应明确权益名称、数量或价值摘要。

### 促销生效

- 促销到达生效条件后才能被引用。
- 生效促销应限制适用车型、门店、客户类型或库存范围。
- 促销可以与市场活动关联，但必须保持独立业务含义。

### 报价引用

- 报价引用促销时应记录使用的促销政策和优惠摘要。
- 不满足适用条件时不得引用。
- 超出促销规则的额外优惠应进入报价审批或主管确认。

### 暂停、结束和作废

- 促销暂停后不能用于新报价，但不影响已确认报价的历史展示。
- 促销结束后不能继续新增使用。
- 促销作废应记录原因，并区分作废前已产生的业务影响。

## 关键业务规则

- 促销政策不应直接修改商品基础价格。
- 促销优惠和销售手工折扣应区分来源。
- 百分比折扣应表达为成交价格比例，例如八折对应 0.8，而不是 8 或 80。
- 金额类优惠应明确为每件直减、整单直减或满额减免中的一种，页面文案、计算方式和结算结果必须一致。
- 多个促销能否叠加必须有明确规则。
- 促销必须校验适用商品、有效时间、状态、优惠类型和值域。
- 促销预算或数量有限时，应记录使用和剩余情况。
- 已在订单中确认的促销，不得因促销结束而消失。
- 促销数据应支持追溯，不能只展示当前可用政策。

## 指标要求

促销政策应支持观察：

- 促销使用次数。
- 促销关联报价数量。
- 促销关联订单数量。
- 促销带来的成交金额。
- 优惠金额或权益成本摘要。
- 预算或名额消耗。
- 促销转化率。

## 验收场景

- 草稿促销不会出现在销售报价可选列表中。
- 生效促销只能被符合车型和时间条件的报价使用。
- 暂停促销后，新报价不能继续引用。
- 订单详情能看到成交时使用的促销政策摘要。
- 促销结束后，历史订单仍保留促销关系。
- 多个促销不可叠加时，报价不能同时选择。
- 管理者能查看促销使用和成交贡献。

## 状态与事件边界

- 拥有状态：草稿、待生效、生效中、已暂停、已结束、已作废和已用尽。
- 消费事件：商品上架、预算调整、报价引用、订单确认和促销作废。
- 发出事件：促销生效、促销暂停、促销结束、促销作废、促销引用和促销快照生成。
- 终态包括已结束、已作废和已用尽；已暂停为可恢复态。
- 不允许促销状态覆盖报价审批、订单成立和成交金额事实。
