# 促销政策业务范围与边界

## 业务目标

促销政策用于管理门店或品牌在指定时间、车型、客户范围内提供的优惠、赠品、补贴或服务权益，帮助销售在报价时使用合规的价格和权益。

促销政策是报价依据之一，不等同于市场活动，也不等同于最终成交价格。

## 目标用户

- 销售人员：查看可用促销并在报价中引用。
- 销售主管：控制优惠边界和审批例外。
- 市场人员：配合活动制定促销主题。
- 管理者：观察促销使用、预算消耗和成交贡献。

## 功能范围

促销政策覆盖：

- 促销创建。
- 适用车型和库存范围。
- 适用客户范围。
- 优惠类型。
- 优惠金额或权益摘要。
- 生效和失效时间。
- 预算或数量限制。
- 叠加规则。
- 使用申请。
- 使用核销。
- 促销效果分析。

## 促销类型

促销类型至少包括：

- 现金优惠。
- 置换补贴。
- 金融贴息。
- 精品赠送。
- 保养权益。
- 保险补贴。
- 限时特价。
- 库存清理优惠。

涉及金融、保险或售后权益时，系统只记录销售承诺和业务关系，不承担专业系统审批职责。

## 促销状态

促销状态应至少区分：

- 草稿。
- 待生效。
- 生效中。
- 已暂停。
- 已结束。
- 已作废。

已结束促销仍应保留历史报价和订单引用关系。

## 非目标

促销政策不承担：

- 广告素材投放。
- 会员积分体系。
- 金融贷款审批。
- 保险承保。
- 售后服务套餐履约。
- 财务预算系统。
- 自动化价格引擎。

## 成功标准

- 销售能在报价时看到当前可用促销。
- 促销适用范围、有效期和叠加规则清晰。
- 促销使用能够与报价和订单关联。
- 过期、暂停或作废促销不能用于新报价。
- 管理者能观察促销带来的成交和让利情况。
