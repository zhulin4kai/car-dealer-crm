# 市场活动流程规则与验收规格

## 主流程

### 活动计划

- 活动创建时应明确主题、类型、时间、负责人和目标。
- 活动可以关联目标车型、促销政策或客户群体。
- 活动预算可以作为经营分析依据，但不替代财务成本系统。
- 草稿活动不应产生对外承诺或线索归因。

### 活动执行

- 活动进行中可以登记线索、导入线索或关联已有客户。
- 活动线索必须保留活动来源。
- 销售承接活动线索后，应按线索规则跟进。
- 活动期间产生的客户、商机、试驾和订单应能回溯到活动。

### 活动结束与复盘

- 活动结束后应统计线索、有效客户、商机、试驾、报价和成交。
- 活动复盘应记录转化表现、投入产出和主要问题。
- 已复盘活动不应随意修改成本、时间、负责人和核心结果。

## 关键业务规则

- 活动是来源归因，不是客户状态。
- 一个线索可以有主要来源活动；多个触点可以作为辅助来源记录。
- 活动成本用于 ROI 粗略分析，不应与正式财务账混淆。
- 活动关闭不应自动关闭其产生的线索或商机。
- 已产生线索、客户、商机、报价或订单的活动不得物理删除。
- 活动备注、线索来源和成交归因属于历史事实，不得通过级联删除来清理活动。
- 活动导出和活动客户明细应受权限控制。
- 活动数据不得被销售为了提高个人业绩随意改来源。

## 指标要求

市场活动应支持观察：

- 活动线索数量。
- 有效线索数量。
- 转客户数量。
- 转商机数量。
- 试驾数量。
- 报价数量。
- 成交数量。
- 成交金额。
- 活动成本。
- 单线索成本。
- 单成交成本。
- 活动 ROI。

## 验收场景

- 市场人员创建活动后，可以把新线索归因到该活动。
- 活动产生的线索转客户后，客户仍保留活动来源。
- 活动结束后，后续成交仍可计入活动转化观察。
- 已复盘活动不能被普通人员随意修改核心成本和时间。
- 管理者能查看不同活动的线索到成交转化漏斗。
- 无权限用户不能导出活动客户明细。

## 状态与事件边界

- 拥有状态：草稿、待开始、进行中、已结束、已复盘、已关闭和已取消。
- 消费事件：活动计划批准、线索进入、线索转客户、商机赢单和订单完成。
- 发出事件：活动开始、活动结束、活动复盘、活动关闭和来源归因。
- 终态包括已复盘、已关闭和已取消；已结束到已复盘为可处理态。
- 不允许活动状态覆盖线索、客户、商机、订单和成交状态。
